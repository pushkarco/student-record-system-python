## Project Description
A menu-driven Python program for storing and managing student academic records using Python collections.

## Features
- Add, search, update and delete student records
- Display all records
- Calculate average marks
- Find the highest scorer by average marks
- List students by department
- Count student records
- Display unique departments, subjects and clubs

## Python Concepts Used
- Strings
- Lists
- Tuples
- Sets
- Dictionaries
- Functions, loops and conditional statements
- Basic input validation

## Requirements
- Python 3
- No external libraries required

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python student_management.py
   ```

4. Choose an option from the menu.

## Note
Student records are stored in memory while the program runs. They are not saved to a file or database, so they reset when the program closes.
