# Screenshots Checklist

## Purpose

This checklist helps capture genuine screenshots of the Student Record and Academic Management System while it runs in the terminal.

## Instructions

1. Open the project in Visual Studio Code.
2. Open the integrated terminal.
3. Run the program using:

   `python application/student_management.py`

4. Perform each operation using sample student details.
5. Capture the terminal after the result appears.
6. Save the screenshots in the `screenshots` folder.

## Screenshot Checklist

- [ ] 01_main_menu.png — Main menu displayed when the program starts.
- [ ] 02_add_student.png — Adding a student record.
- [ ] 03_display_records.png — Displaying stored student records.
- [ ] 04_search_student.png — Searching for a student.
- [ ] 05_update_student.png — Updating a student record.
- [ ] 06_delete_student.png — Deleting a student record.
- [ ] 07_average_marks.png — Calculating average marks.
- [ ] 08_highest_scorer.png — Finding the highest scorer, if supported by the program.
- [ ] 09_input_validation.png — Handling invalid input.
- [ ] 10_exit_program.png — Exiting the program.

## Important Notes

- Capture screenshots from the actual running program.
- Use sample data rather than personal student information.
- Only capture operations that are supported by the current source code.
- Do not mark a screenshot as completed until it has been captured and saved.
