# Student Record and Academic Management System

## 1. Introduction

The Student Record and Academic Management System is a menu-driven Python program developed to store and manage student academic records. The project demonstrates the use of Python collections for organizing and processing data.

## 2. Objectives

- To store student records in an organized manner.
- To add, search, update, and delete student records.
- To display student information.
- To perform basic academic calculations.
- To understand the use of Python dictionaries, lists, and other basic programming concepts.

## 3. Tools and Technologies

- **Programming Language:** Python 3
- **Editor:** Visual Studio Code
- **Version Control:** GitHub

## 4. Data Organization

The program uses a Python dictionary to store student records. Dictionaries allow records to be associated with keys, making it easier to access and manage student information.

The program also uses functions, conditional statements, loops, and input validation to perform different operations.

## 5. Main Features

The program is designed to provide student record management operations through a menu. These include adding, searching, updating, and deleting records, displaying records, and performing academic calculations supported by the source code.

## 6. How to Run the Program

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal and run:

   `python application/student_management.py`

   On Windows, `py application/student_management.py` can also be used.

5. Follow the menu displayed in the terminal.

## 7. Limitations

The records are stored in memory while the program runs. They are not permanently saved to a file or database, so the records are lost when the program exits.

## 8. Conclusion

This project demonstrates how Python collections can be used to organize and manage student academic information. It also provides practical experience with functions, loops, conditions, input validation, and menu-driven programming.
