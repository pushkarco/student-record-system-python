# Test Cases – Student Record and Academic Management System

## 1. Purpose

These test cases describe scenarios to check the behavior of the Python program. Run each test and record the actual result before marking it as passed.

## 2. Test Cases

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Start the program | The main menu should be displayed. |
| TC02 | Select the add-student option and enter valid details | The student record should be added. |
| TC03 | Enter empty input where a value is required | The program should request valid input. |
| TC04 | Search for an existing student | The matching record should be displayed. |
| TC05 | Search for a student who does not exist | An appropriate message should be displayed. |
| TC06 | Update an existing student record | The selected record should be updated. |
| TC07 | Delete an existing student record | The selected record should be removed. |
| TC08 | Display all student records | Stored records should be displayed. |
| TC09 | Calculate average marks | The program should display the calculated average. |
| TC10 | Exit the program | The program should stop normally. |

## 3. Testing Notes

- Use sample student details when testing.
- Check the displayed output after each operation.
- Confirm that invalid inputs are handled appropriately.
- Record the actual result after running each test.

**Note:** These are planned test cases. Mark a test as passed only after verifying it against the running program.
